# Сборка APK прямо с телефона через GitHub

1. Открой GitHub в браузере и создай бесплатный аккаунт.
2. Создай новый репозиторий, например `baha-rp-launcher`.
3. Распакуй этот ZIP на телефоне и загрузи **содержимое папки** в репозиторий. В корне должны находиться `build.gradle`, `settings.gradle`, `app/` и `.github/`.
4. Открой вкладку **Actions**.
5. Выбери **Build BAHA RP Launcher APK**.
6. Нажми **Run workflow**.
7. После окончания сборки открой завершившийся workflow и скачай артефакт **BAHA-RP-Launcher-debug**.
8. Внутри будет `app-debug.apk`.

Сборка выполняется на серверах GitHub. Android Studio на телефоне не требуется.

Важно: лаунчер запускает установленный клиент `com.blackhub.bronline`. Точный механизм автоматического подключения клиента к `144.124.192.40:7777` в исходном APK не был подтверждён, поэтому лаунчер не обещает автоматический вход на сервер.
